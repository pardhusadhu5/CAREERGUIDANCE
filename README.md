# Career Decision Simulator

A full-stack web application built with React (Next.js) and Node.js that helps students make informed career decisions by simulating different career paths using AI predictions based on market data.

## Features

- Explore multiple career paths
- AI-powered predictions for salary progression
- Job demand analysis
- Automation risk assessment

## Tech Stack

- **Frontend**: React with Next.js (App Router), TypeScript, Tailwind CSS
- **Backend**: Next.js API routes (Node.js)
- **AI**: Integrated AI service for predictions
- **Styling**: Tailwind CSS

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

- `app/`: Next.js app directory with pages and API routes
- `components/`: Reusable React components
- `lib/`: Utility functions and AI integration
- `public/`: Static assets

## API Endpoints

- `GET /api/careers`: Fetch available career options
- `POST /api/simulate`: Run career simulation with AI predictions
